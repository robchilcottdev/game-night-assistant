# Game Night Assistant
This is the node.js backend and config for the Game Night Assistant add-on / app for Home Assistant, still in early development. General idea is to make a toolkit for keeping score of various board and card games, but to add a little Home Assistant spice - e.g. when you reach a certain score, or zero points is scored in a game of Farkle, trigger your Home Assistant script to play a sound, flash lights, etc. Make game night a little more chaotic :)

The plan is to implement this at some point as a proper HA app so it can be installed in your own Home Assistant instance, but I'm completely new to this and I'm not quite there yet...
